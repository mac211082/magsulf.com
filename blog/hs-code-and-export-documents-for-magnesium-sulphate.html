HS Code 2833.21 and the Export Documents for Magnesium Sulphate

14 Apr 2025 · 6 min read · magsulf.com

Getting the paperwork right is what turns a good price into a smooth delivery. This is the document set we prepare for magnesium sulphate shipments from India.

The HS code

Magnesium sulphate is classified under HS heading 2833.21 (sulphates of magnesium). National tariff lines add further digits, and some countries classify fertilizer-grade material differently, so importers should confirm the code with their customs broker before the first shipment. Natural kieserite, a mined mineral, falls under a different heading.

Standard export documents

  • Commercial invoice — price, Incoterm, HS code and buyer details.
  • Packing list — bag count, net and gross weights, marks and batch numbers.
  • Bill of Lading — issued by the shipping line once the container is loaded.
  • Certificate of Origin — confirms Indian origin, and can support duty preferences under trade agreements.
  • Certificate of Analysis — batch test results.
  • Safety Data Sheet (SDS/MSDS) — handling and safety information.

Market-specific documents

Some destinations require extra paperwork, such as pre-shipment conformity certificates, fertilizer or feed registration, phytosanitary certificates or import permits. Requirements change, so we confirm them with each buyer and their clearing agent before quoting.
